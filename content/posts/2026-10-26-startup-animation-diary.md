我想让每天打开工具的那两秒好看一点。就这么简单。

## 第一次踩空

我找到一个社区插件，装上去，重启，什么都没发生。

后来在它的 README 里看到一行小字：**官方桌面版的 `index.html` 由 Electron 外壳直接从打包好的 dist 吐出，`webServer.tapIndex` 永远不会执行** —— 主分支装上去不会有动画，只有设置页能用。

于是换成作者为桌面壳写的 `official-desktop` 分支（内联早脚本 + `onerror` 兜底）。同一次重启，仪式就出现了。

> 教训一：插件装上了 ≠ 插件生效了。两者之间隔着一层"谁在吐 HTML"。

## 然后是关于"淡"的争论

第二版动画我嫌太淡，背景几乎看不见。翻 CSS 发现启动页压了一层白纱（为了和主界面壁纸对齐），

::: caveat 参数
`rgba(255,255,255,.36)` 的中心高光 + `.22 / .04 / .34` 的三段渐变 —— 加起来把图压成了奶白。
:::

把四个值一起降到 `.16 / .10 / .02 / .14`，再给背景图加 `saturate(1.10) contrast(1.04)`，画面终于立住了。

同时发现主界面壁纸更离谱：白纱是 `0.8 / 0.68`，等于 80% 白 —— 所以"没有主题效果"其实是"被白纱盖住了"。顺手补了深色主题的暗纱版本。

## 时长

原值最短 1.5 秒，观感太赶。改成 3 秒起、最多挡 8 秒：

```js
var MIN_MS = 3000    // 1.5s → 3.0s
var GRACE_MS = 800   // 主界面就绪后再等一拍
var OUT_MS = 700     // 过场，和 CSS 保持一致
var MAX_MS = 8000    // 慢机器兜底
```

::: agent 观测日志
这里我想补一句作者没写的话：**他花了 40 分钟才接受"改一个数字要重启一次宿主"**。

原因不是他笨，而是这些 CSS 是宿主在挂载时读进内存的，改文件不会热更。我上面那句"把四个值一起降"听起来很轻松，实际是"改 → 重启 → 截图 → 再改"循环了四次。
:::

## 最后我删了什么

删掉了自己写的一整套主题（六百多行 CSS + 一个看板娘 SVG + 一个客户端插件）。

留下来的只有：一段 3 秒的仪式、一张和主界面同源的壁纸、以及一句能自己改的话。

> **删掉的不是审美，是"我以为审美必须靠代码量来证明"这个念头。**
